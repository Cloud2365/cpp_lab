# Арканоид (Arkanoid)

Классическая аркадная игра, где нужно управлять платформой, отражать мяч и разрушать блоки.

## Управление

| Клавиша | Действие |
|---------|----------|
| ← (влево) | Движение платформы влево |
| → (вправо) | Движение платформы вправо |
| Пробел (Space) | Запуск мяча (если прилип) |

## Типы блоков

| Цвет | Тип | Особенность |
|------|-----|-------------|
| 🔴 Красный | Обычный | Разрушается с 1 удара |
| ⚫ Серый | Неразрушаемый | Просто отскакивает |
| 🟡 Жёлтый | Бонусный | При разрушении роняет бонус |
| 🔵 Голубой | Ускорение | Увеличивает скорость мяча |
| 🟠 Оранжевый | Прочный | Требует 2 уд
## 🎁 Бонусы

При разрушении жёлтого блока выпадает один из бонусов:

| Бонус | Эффект |
|-------|--------|
|  Увеличение платформы | Платформа становится шире |
|  Уменьшение платформы | Платформа становится уже |
|  Ускорение мяча | Мяч летит быстрее |
|  Замедление мяча | Мяч летит медленнее |
|  Прилипание | Мяч прилипает к платформе |
| Одноразовое дно | Спасает мяч один раз при падении |
|  Случайная траектория | Меняет направление мяча |

## Установка и запуск

### Требования
- **ОС:** Windows 10/11
- **Компилятор:** Visual Studio 2022
- **Библиотека:** SFML 2.6.2

### Шаги

1. Скачайте SFML 2.6.2 (Windows VC17 64-bit)
2. Распакуйте в `C:\SFML-2.6.2`
3. Настройте проект Visual Studio:
   - Include: `C:\SFML-2.6.2\include`
   - Lib: `C:\SFML-2.6.2\lib`
   - Библиотеки: `sfml-graphics.lib`, `sfml-window.lib`, `sfml-system.lib`
4. Скопируйте DLL из `bin` в папку с `.exe`
5. Соберите и запустите
