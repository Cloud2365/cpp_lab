# README — Игра GEMS 

## Описание

**GEMS** — это классическая игра с игровым полем 8×8 клеток с разноцветными цветами.  
Цель: менять местами соседние клетки, чтобы собрать три и более одинаковых самоцвета в ряд (по горизонтали, вертикали или кластером). После уничтожения клетки сверху падают новые, что может вызывать цепные комбинации.

## Возможности

- Случайная генерация поля без начальных совпадений.
- Обмен соседних клеток мышью.
- Подсветка выбранной клетки.
- Автоматическое удаление кластеров (групп) размером ≥3 (любой формы, не только линия).
- Гравитация (падение клеток) и заполнение пустот новыми клетками.
- Бонусы: перекрашивание 3 клеток в радиусе и бомба (уничтожает 5 случайных клеток).


## Требования

- **Библиотека**: SFML 2.6.2 (скачать (https://github.com/SFML/SFML/releases/tag/2.6.2))

## Установка и запуск (Windows)

### 2. Скачайте и настройте SFML
- Скачайте **SFML 2.6.2** для Visual Studio 2022 (64‑bit):  
  `SFML-2.6.2-windows-vc17-64-bit.zip`
- Распакуйте архив, например, в `C:\SFML-2.6.2`.
- В Visual Studio откройте свойства проекта:
  - **C/C++ → Общие → Дополнительные каталоги включаемых файлов** → добавьте `C:\SFML-2.6.2\include`
  - **Компоновщик → Общие → Дополнительные каталоги библиотек** → добавьте `C:\SFML-2.6.2\lib`
  - **Компоновщик → Ввод → Дополнительные зависимости** → добавьте:
    ```
    sfml-graphics.lib
    sfml-window.lib
    sfml-system.lib
    ```
- Скопируйте DLL‑файлы из `C:\SFML-2.6.2\bin` в папку с вашим исполняемым файлом (обычно `x64\Debug`). Для **Debug** используйте версии с `-d` (например, `sfml-graphics-d-2.dll`), для **Release** — без `-d`.


## Управление

- **Клик левой кнопкой мыши** по клетке — выбрать клетку.
- **Клик по соседней клетке** — обменять их.
- Если после обмена образуется комбинация (кластер ≥3), клетки удаляются, сверху падают новые, возможны бонусы.
- Игра заканчивается, когда игрок закрывает окно.

## Бонусы

- **Перекрашивание** (30% шанс): случайная клетка в радиусе 3 от кластера и две её несоседние клетки перекрашиваются в цвет источника.
- **Бомба** (30% шанс): уничтожает 5 случайных клеток на поле.
